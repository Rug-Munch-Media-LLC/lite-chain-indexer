# SECURITY AUDIT — lite-chain-indexer

**Date:** 2026-09-19
**Auditor:** `audit-security` (GLM-5.3-Flash, read-only pass; agent hit its step budget before writing this file — evidence below was recorded in its verified findings and transcribed by the lead)
**Scope:** api/, mcp_server.py, webhooks/, plugin/, storage SQL surfaces, RPC URL/credential handling, deploy units.
**Method:** source reads + one live DuckDB reproduction on Talos; context-crypto `query_security_context` for BAD/GOOD baselines.

## P1

### SEC-1 — SQL-injection primitive in `historical._lit` (proven, currently latent)
- `lite_indexer/storage/historical.py:~745` — `_lit` escapes `'` as `\'` (ClickHouse style), but the rendered `portable_where` is executed by **DuckDB** in `lite_indexer/storage/cold_store.py:539-547`.
- Reproduced on Talos: payload `zzz'\nOR 1=1)\n--` in a bound param yields `WHERE (owner = 'zzz\'\nOR 1=1)\n--')` → DuckDB parses it and the injection executes (returns all rows).
- Impact if reachable: arbitrary DuckDB SQL in the API process (row-filter bypass; local file read via `read_csv`).
- **Reachability today: LATENT.** Every `api/` router SQL was traced; none currently satisfies `historical._parse_sql` (all have AS-aliases, OR, GROUP BY, JOIN, subqueries, or non-AVAILABLE_TABLES tables). No live HTTP path today.
- Fix: escape with `''` doubling (as `cold_store._lit:239` already does); add a regression test on `_lit` round-trip through DuckDB parsing.

### SEC-2 — Unauthenticated B2 archive HTTP server bound to all interfaces
- `scripts/serve-b2-http.sh:38-41` — `rclone serve http b2-crypt:chain-data --addr :8090 --no-auth`.
- Anyone who can reach Talos:8090 reads the entire parquet archive. Fix: bind `127.0.0.1` (or Tailscale iface) and/or require auth; verify firewall exposure of 8090. [REVIEW: confirm whether the service is actually running/units enabled.]

### SEC-3 — Webhook SSRF + unauthenticated management endpoints
- `lite_indexer/webhooks/router.py:54-60` — registration validates only `https://` scheme; `https://127.0.0.1:PORT` and `https://169.254.169.254` pass.
- `lite_indexer/webhooks/sender.py:141` — POSTs to the stored URL with no private-IP/link-local blocking.
- `GET /api/v1/webhooks/{id}/logs` and `DELETE /api/v1/webhooks/{id}` have **no auth** (only registration is rate-limited) → anyone can delete webhooks or use delivery logs (status codes/timing) as an internal-service probing oracle.
- Fix: resolve-then-block loopback/RFC1918/link-local (with redirect re-check), auth on management routes.

## P2

### SEC-4 — API keys at rest in plaintext, world-readable default umask
- `lite_indexer/rpc/throttle.py:226-237` persists full endpoint URLs (with embedded provider keys) to `rpc_throttle.json`. Quota ledger hashes keys correctly (`rpc/ledger.py:307-355`); log redaction exists and is applied (`logging.py:19-70`) — this file is the gap.
- Fix: chmod 600 (or store only hashed provider ids + a state dir with 0700).

### SEC-5 — Internal detail leaks on public endpoints
- `api/routers/query.py:59` returns raw ClickHouse errors to clients.
- `api/routers/system.py:93-118` `/health` leaks state-dir paths, CH version, error strings.
- `/metrics` is public/unauthenticated.
- Fix: generic client errors + server-side correlation id; sanitize /health; decide /metrics exposure per deployment.

### SEC-6 — GraphQL has no depth/complexity limit
- `api/graphql.py` — strawberry schema with only a per-IP 100/min limit; nesting-depth DoS possible.
- Fix: query depth/complexity caps at the schema layer.
