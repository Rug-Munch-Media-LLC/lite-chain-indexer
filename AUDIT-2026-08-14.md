## 1. Summary Verdict

**Performing: healthy and shipping.** The indexer is in good shape: the full test suite passes
(805 passed / 5 skipped), mypy strict is clean (133 files), the launch-detection / Robinhood /
bundle-detection feature set landed recently is **wired end-to-end** (strategy → buffers →
ClickHouse + NATS fan-out, migrations 007/008/009 present), and production-scale claims
(359M+ rows, 17 chains) are consistent with the code paths and config surface.

The main weaknesses are **integration-surface gaps, not engine breakage**: the newest, most
valuable signals (Solana/Tron token launches, Jito bundle detection) are written to ClickHouse
and streamed to NATS but are **not reachable through the public HTTP API** that the bot/backend
consume, and the transfers endpoint cannot serve Solana SPL data. One example script is broken
by the `intel` package removal. The CI `ruff` gate was red (19 errors, all in tests/examples) —
now fixed.

## 3. Integration-Surface Inventory (exposed vs consumed)

### What the indexer EXPOSES
1. **ClickHouse `wallet_memory`** — `evm_transfers` (285M+), `dex_events` (13M+, 90-day TTL), `deployer_events`, `internal_transfers`, `solana_transfers`, `solana_spl_balance_changes`, **`solana_launches`**, **`tron_launches`**, **`solana_bundles`** (migrations 007/008/009), plus `token_meta_ref`, `holder_balances`, `wallet_labels`, `wallet_profiles`, `wallet_entities`, `scam_addresses`, `bridge_mappings`, `token_prices`, `dex_ohlcv_hourly`, `block_checkpoints`, `reconciliation_results`.
2. **HTTP API** (FastAPI, `:8100` / docker `:8101`, rate-limited, read-only) — `/api/v1/transfers/{address}`, `/api/v1/deployers/{address}`, `/api/v1/query` (validated read-only SQL + table allowlist + LIMIT cap, `api/routers/query.py:38-54`), `/api/v1/whales`, `/api/v1/stats`, `/api/v1/search/*` + `/api/v1/similar/*` (vector, gated by `VECTOR_SEARCH_ENABLED`), `/api/v1/status`, `/health`, `/metrics`, GraphQL (`transfers` / `chain_stats` / `whales`, `api/graphql.py:307-335`), HMAC webhooks.
3. **NATS JetStream** (default `NATS_ENABLED=1`, lazy-connect → no startup cost without server) — subjects `chain.*` / `alerts.*`; publishes transfers, DEX, deployer events, whale alerts, **`chain.solana.launch`**, **`chain.solana.bundle`**, **Tron launches** (`lite_indexer/indexer/_writers.py:126-196`). `compose.nats.yml` provides the server.
4. **Parquet → B2 → DuckDB** — daily export cron (`scripts/lite-indexer-parquet-daily.sh`), bootstrap snapshots with manifests.

### Consumed (wired) ✓
- Transfer queries → `/api/v1/transfers` (EVM) + GraphQL + raw `/query`; on-demand RPC fallback (`ON_DEMAND_RPC_ENABLED`).
- Deployer activity → `/api/v1/deployers` + `QueryRouter.get_deployer_info` (`lite_indexer/query/router.py:567`).
- Whale swaps → `/api/v1/whales`; stats → `/api/v1/stats`; vectors → `/api/v1/search|similar`.
- NATS fan-out for launch/bundle events → available to consumers on `chain.solana.*`.

### NOT consumed (gaps — see priorities)
- **Launch + bundle events: ClickHouse + NATS only.** `solana_launches`, `tron_launches`, `solana_bundles` are **absent from the API allowlist** `api/db.py:51-87` (and `TABLE_ALIASES`) and have **no router endpoint**. A bot/backend cannot query "what launched in the last hour" over HTTP.
- **Solana transfers via API: empty.** `/api/v1/transfers/{address}?chain=solana` runs `WHERE chain='solana'` against `evm_transfers` (`api/routers/transfers.py:125-134`) — always zero rows; SPL data lives in `solana_spl_balance_changes`/`solana_transfers`. Docstring advertises `chain=solana` (`transfers.py:55`).
- **Internal-transfer traces: queryable only via raw `/query`** (in allowlist) — no dedicated endpoint; `trace` router removed in `abaf431`.
- **Entity traces (intel/forensics): removed entirely** (`abaf431`) — no longer exposed anywhere.
